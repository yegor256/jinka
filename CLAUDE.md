# Instructions for Coding Agents

Keep `README.md` short.
It explains what `jinka` does, how to install it, and how to run it
  on a directory of wishes, and it stops right after the promise
  that your wish will come true.
Never put usage details into `README.md`,
  and never describe command line options there:
  no list of arguments, no defaults, no tuning examples.
The usage line printed by `bin/jinka.js` is the only place
  where command line options are documented.
